Политика конфиденциальности

Приложение VOIDWAKE (пакет ru.voidwake.game)
Дата редакции: 21 сентября 2026 г.

1. Общие положения

Настоящая Политика описывает, какие данные обрабатывает мобильное приложение VOIDWAKE при распространении через RuStore и иные каналы. Используя приложение, вы соглашаетесь с условиями этой Политики.

2. Какие данные обрабатываются

В версии 1.1.0 приложение работает в основном офлайн и:

  • сохраняет на устройстве локальную таблицу рекордов и имя пилота (через хранилище WebView / localStorage);
  • может сохранять настройки звука и служебные параметры игры на устройстве;
  • не требует регистрации и входа в аккаунт;
  • не запрашивает доступ к контактам, камере, микрофону, геолокации;
  • при включённом онлайн-лидерборде (опционально) может отправлять на сервер разработчика имя пилота, счёт и номер волны для таблицы рекордов; без включённого URL данные остаются только на устройстве;

3. Разрешения Android

Может присутствовать разрешение INTERNET как часть оболочки WebView. В версии 1.0.0 игровой процесс и рекорды не зависят от сети. Отдельные рекламные и аналитические SDK не подключены.

4. Передача третьим лицам

Персональные данные пользователей третьим лицам не передаются. При установке из RuStore действуют также правила и политика магазина RuStore.

5. Хранение и удаление

Локальные данные хранятся только на устройстве пользователя. Удаление приложения или очистка данных приложения в настройках Android удаляет сохранённые рекорды и настройки.

6. Дети

Приложение не предназначено для сбора данных детей. Рекомендуемый возрастной рейтинг уточняется в карточке RuStore (ориентир: 6+/игровая аркада без вредоносного контента).

7. Изменения политики

При существенных изменениях (например, появление онлайн-лидерборда, аналитики или покупок) Политика будет обновлена, а дата редакции — изменена. Актуальная версия публикуется по этому адресу.

8. Контакты

По вопросам обработки данных и публикации VOIDWAKE свяжитесь с разработчиком через контакты, указанные в карточке приложения в RuStore.
